# Kumi: все надписи экрана «Сегодня»

Выписано из кода сборки 51 (`App/Views/Tabs/TodayView.swift`, `App/Model/AppModel.swift`). N, M и K подставляются из данных.

## Всегда

- Над заголовком (Caveat): «Сегодня · Чт, 5 ноября» (день недели и дата меняются)
- Ссылка: «или выбрать тему в Каталоге»
- Карточка «Выражение дня»: «Выражение дня», само выражение, перевод (или значение по-английски, если перевод выключен), кнопка звука «Послушать: …»

## План ещё не выполнен

- Заголовок: «N карточка / карточки / карточек на сегодня»
- Карточка плана, первая строка: «N повторение / повторения / повторений»
  - подпись: «подошёл срок, идут первыми»
  - или, если повторений нет: «сегодня сроков нет»
- Карточка плана, вторая строка: «новое выражение» (если одно) или «новых выражения / выражений»
  - подпись: «Работа и карьера, Путешествия · B1» (две выбранные темы и уровень)
  - или, если темы не выбраны: «уровень B1»
- Подсказка со значком i: «Рекомендуется не больше 10 новых фраз в день.»
- Главная кнопка: «Начать занятие»
  - или, если есть незаконченное занятие: «Начать заново»
- Если занятие было прервано, сверху карточка: «Продолжить занятие», под ней «шаг N из M»

### Окно по нажатию на подсказку

Заголовок «Почему столько карточек», кнопка «Понятно». Текст состоит из двух абзацев:

1. «Сначала идут выражения, у которых подошёл срок повторения: сегодня их N, в занятие берём не больше 50.»
2. Одна из фраз:
   - «Сегодня догоняем повторения: новых не будет, остаток перейдёт на следующее занятие без штрафа.» (просроченных повторений больше лимита)
   - «Новые выражения вашего уровня закончились.»
   - «Новых — не больше 10 в день. На вашем уровне осталось K выражений.» (новых меньше лимита)
   - «Новых — не больше 10 в день, K вы уже начали сегодня.»
   - «Новых — не больше 10 в день.»

## План выполнен

- Заголовок: «Вы молодец!»
- Жёлтая карточка «Сегодня» (только строки больше нуля; если всё ноль, карточки нет):
  - «Освоили — N фразу / фразы / фраз»
  - «Повторили — N фразу / фразы / фраз»
  - «Начали учить — N фразу / фразы / фраз»
  - «Время — N мин»
  - если новые на уровне закончились, ссылка: «Новые уровня B1 закончились · перейти на B2»
- Бирюзовая карточка (если есть тема с новыми): «Продолжить тему», «Путешествия · B1», «N новое / новых →»
- Лиловая карточка (если сегодня начаты новые): «Новые сегодня», ссылка «все N», до трёх выражений с переводом
- Лист по ссылке «все N»: заголовок «Новые сегодня»

- Кнопки: «Напоминать», «Не сейчас»
